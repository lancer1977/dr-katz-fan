# Dr. Katz Fan

A fan-made archive for *Dr. Katz, Professional Therapist* (Comedy Central, 1995–2002) —
the comedians who passed through Katz's office, their quips, and (where they exist)
episode transcripts.

## Structure

- `data/episodes.json` — episode list with air dates and guest comedian(s)
- `data/quotes.json` — collected quotes, sourced from TV Tropes / Quote Catalog / IMDb
- `data/transcript-sources.md` — findings on where (if anywhere) real transcripts exist
- `src/` — the site itself (TBD)
- `scripts/` — scrapers used to build the data set

## Status
